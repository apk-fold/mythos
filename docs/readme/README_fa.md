**همگام‌سازی با کد ۴ رقمی**: روی یک دستگاه *همگام‌سازی ← نمایش کد* و روی دیگری *وارد کردن کد* را انتخاب کنید. کد فقط برای پیدا کردن یکدیگر روی یک رله (ntfy.sh، قابل تغییر در تنظیمات) به کار می‌رود و دعوت‌نامه در آنجا رمزنگاری‌شده است. پس از آن اسناد شما مستقیماً از یک دستگاه به دستگاه دیگر می‌روند.

واژه‌پرداز، صفحه‌گسترده و ارائه در یک برنامه، برای **Windows، Linux و Android**.
فایل‌ها روی دستگاه‌های شما می‌مانند؛ همگام‌سازی مستقیماً از دستگاهی به دستگاه دیگر انجام می‌شود.

## نصب

| سیستم | فایل | محل |
|---|---|---|
| Windows | `Mythos-Setup-1.1.0.exe` (نصب‌کننده) یا `Mythos-Portable-1.1.0.exe` | `release/` |
| Linux | `Mythos-1.1.0-x64.tar.gz` (از حالت فشرده خارج کنید و `./mythos` را اجرا کنید)؛ AppImage روی Linux با `npm run dist:linux` ساخته می‌شود | `release/` |
| Android | `app-debug.apk` | `android/app/build/outputs/apk/debug/` |

فایل‌ها امضا نشده‌اند: Windows SmartScreen انتخاب «اطلاعات بیشتر ← در هر صورت اجرا شود» را می‌خواهد،
و Android اجازهٔ نصب برنامه از منابع ناشناس را درخواست می‌کند.

## ساخت دوباره

```sh
npm install
npm run dev          # نسخهٔ مرورگر برای توسعه (http://localhost:5173)
npm start            # برنامهٔ دسکتاپ
npm run dist:win     # نصب‌کنندهٔ Windows → release/
npm run dist:linux   # AppImage + tar.gz → release/ (ترجیحاً روی Linux اجرا شود)
npm run android      # سایت را در android/ کپی می‌کند، سپس:
cd android && gradlew assembleDebug   # JAVA_HOME = JDK 21
```

## همگام‌سازی بدون سرور

هر سند یک **Yjs CRDT** است که در IndexedDB ذخیره می‌شود. دو دستگاه که یک سند را به‌صورت آفلاین ویرایش کرده‌اند،
تغییراتشان را به‌طور خودکار ادغام می‌کنند؛ بدون تعارض و بدون قاعدهٔ «آخرین نسخه برنده است».

سه راه برای پیوند دادن دستگاه‌ها (پنل **همگام‌سازی**):

1. **جفت‌سازی مستقیم (WebRTC)**: دستگاه A یک کد QR دعوت نشان می‌دهد، B آن را اسکن می‌کند (یا کد را می‌چسباند)
   و یک کد QR پاسخ نشان می‌دهد که A به نوبهٔ خود اسکن می‌کند. از آن پس اتصال سرتاسری رمزنگاری می‌شود (DTLS)
   و بی‌درنگ است. در Wi-Fi محلی هیچ سروری استفاده نمی‌شود؛ گزینهٔ «از طریق اینترنت» از یک سرور STUN عمومی
   فقط برای یافتن نشانی عمومی استفاده می‌کند (هیچ داده‌ای از آن عبور نمی‌کند). باید با هر بار باز کردن برنامه تکرار شود.
2. **پوشهٔ مشترک** (Windows / Linux): پوشه‌ای که با Syncthing همگام می‌شود، یک حافظهٔ USB یا یک پوشهٔ اشتراکی شبکه را انتخاب کنید.
   هر دستگاه فایل `mythos-<id>.mythos` خودش را در آن می‌نویسد و فایل‌های دیگران را هر ۵ ثانیه می‌خواند.
3. **فایل `.mythos`**: برون‌بری/درون‌بری دستی کل فضای کار (ایمیل، حافظهٔ USB…). درون‌بری ادغام می‌کند و چیزی را بازنویسی نمی‌کند.

دستگاه‌ها تغییرات را به هم منتقل می‌کنند: اگر A به B و B به C وصل باشد، تغییرات A به C هم می‌رسد.

## قالب‌های پشتیبانی‌شده

| | درون‌بری | برون‌بری |
|---|---|---|
| متن | .docx, .html, .txt, .md | .docx, PDF (چاپ) |
| صفحه‌گسترده | .xlsx, .xls, .ods, .csv | .xlsx, .csv |
| ارائه | .pptx | .pptx, PDF (چاپ) |

برای تحلیل نحوهٔ کار Word، Excel و PowerPoint که راهنمای طراحی بوده است، [docs/ANALYSE.md](../../docs/ANALYSE.md) (به فرانسوی) را ببینید.

## ساختار

```
src/main.js            صفحهٔ اصلی، مسیریابی، درون‌بری فایل
src/store.js           ذخیره‌سازی محلی (Y.Doc + IndexedDB)، کتابخانه
src/sync/              پروتکل همگام‌سازی، WebRTC، پوشهٔ مشترک، رابط
src/apps/writer.js     واژه‌پرداز (ProseMirror/Tiptap)
src/apps/sheet.js      صفحه‌گسترده (شبکهٔ canvas)
src/apps/formula.js    موتور فرمول
src/apps/slides.js     ارائه‌ها
src/io/                تبدیل‌های docx / xlsx / pptx
electron/              برنامهٔ دسکتاپ (Windows، Linux)
android/               پروژهٔ Android (Capacitor)
```

## محدودیت‌های شناخته‌شده

- متن: ردگیری تغییرات، توضیحات، سرصفحه/پاصفحه و صفحه‌بندی واقعی روی صفحه‌نمایش وجود ندارد
  (شکست صفحه‌ها هنگام چاپ و در .docx رعایت می‌شوند).
- صفحه‌گسترده: نمودار، ادغام سلول‌ها، قالب‌بندی شرطی و جدول محوری وجود ندارد؛
  درون‌بری .xlsx مقادیر، فرمول‌ها، پهنای ستون‌ها و حروف پررنگ را بازمی‌گرداند، نه همهٔ سبک‌ها را.
- ارائه: یک سبک برای هر کادر متن (بدون قالب‌بندی واژه‌به‌واژه)، بدون انیمیشن؛
  درون‌بری .pptx متن‌ها، شکل‌ها، تصاویر، رنگ‌ها و یادداشت‌ها را می‌آورد، اما الگوها و تم‌ها را نه.
- جفت‌سازی مستقیم باید در هر بار اجرا تکرار شود (سروری برای یافتن دستگاه‌ها وجود ندارد).
