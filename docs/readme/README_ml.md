**4 അക്ക കോഡ് വഴി സിങ്ക്**: ഒരു ഉപകരണത്തിൽ *സിങ്ക് → കോഡ് കാണിക്കുക*, മറ്റേതിൽ *കോഡ് നൽകുക*. ഒരു റിലേയിൽ (ntfy.sh, ക്രമീകരണങ്ങളിൽ മാറ്റാം) പരസ്പരം കണ്ടെത്താൻ മാത്രമാണ് കോഡ് ഉപയോഗിക്കുന്നത്, ക്ഷണം അവിടെ എൻക്രിപ്റ്റ് ചെയ്തിരിക്കും. തുടർന്ന് നിങ്ങളുടെ ഡോക്യുമെന്റുകൾ ഒരു ഉപകരണത്തിൽ നിന്ന് മറ്റൊന്നിലേക്ക് നേരിട്ട് പോകുന്നു.

വേഡ് പ്രോസസ്സർ, സ്‌പ്രെഡ്‌ഷീറ്റ്, പ്രസന്റേഷനുകൾ എന്നിവ ഒരൊറ്റ ആപ്പിൽ, **Windows, Linux, Android** എന്നിവയ്ക്കായി.
ഫയലുകൾ നിങ്ങളുടെ ഉപകരണങ്ങളിൽ തന്നെ നിലനിൽക്കുന്നു; സിങ്ക് ഉപകരണങ്ങൾ തമ്മിൽ നേരിട്ട് നടക്കുന്നു.

## ഇൻസ്റ്റാൾ ചെയ്യാൻ

| സിസ്റ്റം | ഫയൽ | സ്ഥാനം |
|---|---|---|
| Windows | `Mythos-Setup-1.1.0.exe` (ഇൻസ്റ്റാളർ) അല്ലെങ്കിൽ `Mythos-Portable-1.1.0.exe` | `release/` |
| Linux | `Mythos-1.1.0-x64.tar.gz` (എക്‌സ്‌ട്രാക്റ്റ് ചെയ്ത് `./mythos` പ്രവർത്തിപ്പിക്കുക); AppImage Linux-ൽ `npm run dist:linux` ഉപയോഗിച്ച് ബിൽഡ് ചെയ്യുന്നു | `release/` |
| Android | `app-debug.apk` | `android/app/build/outputs/apk/debug/` |

ഫയലുകൾ സൈൻ ചെയ്തിട്ടില്ല: Windows SmartScreen "More info → Run anyway" തിരഞ്ഞെടുക്കാൻ ആവശ്യപ്പെടും,
Android അജ്ഞാത ഉറവിടങ്ങളിൽ നിന്നുള്ള ആപ്പുകൾ ഇൻസ്റ്റാൾ ചെയ്യാൻ അനുമതി ചോദിക്കും.

## വീണ്ടും ബിൽഡ് ചെയ്യാൻ

```sh
npm install
npm run dev          # ഡെവലപ്‌മെന്റിനുള്ള ബ്രൗസർ പതിപ്പ് (http://localhost:5173)
npm start            # ഡെസ്‌ക്‌ടോപ്പ് ആപ്പ്
npm run dist:win     # Windows ഇൻസ്റ്റാളർ → release/
npm run dist:linux   # AppImage + tar.gz → release/ (സാധ്യമെങ്കിൽ Linux-ൽ പ്രവർത്തിപ്പിക്കുക)
npm run android      # സൈറ്റ് android/-ലേക്ക് പകർത്തുന്നു, തുടർന്ന്:
cd android && gradlew assembleDebug   # JAVA_HOME = JDK 21
```

## സെർവർ ഇല്ലാത്ത സിങ്ക്

ഓരോ ഡോക്യുമെന്റും IndexedDB-യിൽ സൂക്ഷിക്കുന്ന ഒരു **Yjs CRDT** ആണ്. ഒരേ ഡോക്യുമെന്റ് ഓഫ്‌ലൈനായി എഡിറ്റ് ചെയ്ത രണ്ട് ഉപകരണങ്ങൾ
അവയുടെ മാറ്റങ്ങൾ സ്വയമേവ ലയിപ്പിക്കുന്നു; വൈരുദ്ധ്യമില്ല, "അവസാന പതിപ്പ് ജയിക്കും" എന്ന രീതിയുമില്ല.

ഉപകരണങ്ങൾ ബന്ധിപ്പിക്കാൻ മൂന്ന് വഴികൾ (**സിങ്ക്** പാനൽ):

1. **നേരിട്ടുള്ള ജോടിയാക്കൽ (WebRTC)**: ഉപകരണം A ഒരു ക്ഷണ QR കോഡ് കാണിക്കുന്നു, B അത് സ്കാൻ ചെയ്യുന്നു (അല്ലെങ്കിൽ കോഡ് ഒട്ടിക്കുന്നു)
   തുടർന്ന് ഒരു മറുപടി QR കോഡ് കാണിക്കുന്നു, അത് A സ്കാൻ ചെയ്യുന്നു. അതിനുശേഷം കണക്ഷൻ എൻഡ്-ടു-എൻഡ് എൻക്രിപ്റ്റ് ചെയ്യപ്പെടുന്നു (DTLS),
   തത്സമയം. ലോക്കൽ Wi-Fi-യിൽ ഒരു സെർവറും ഉപയോഗിക്കുന്നില്ല; "ഇന്റർനെറ്റ് വഴി" ഓപ്ഷൻ ഒരു പബ്ലിക് STUN സെർവർ
   പബ്ലിക് വിലാസം കണ്ടെത്താൻ മാത്രം ഉപയോഗിക്കുന്നു (ഒരു ഡാറ്റയും അതിലൂടെ കടന്നുപോകുന്നില്ല). ആപ്പ് തുറക്കുമ്പോഴെല്ലാം ഇത് വീണ്ടും ചെയ്യണം.
2. **പങ്കിട്ട ഫോൾഡർ** (Windows / Linux): Syncthing സിങ്ക് ചെയ്യുന്ന ഒരു ഫോൾഡർ, ഒരു USB സ്റ്റിക്ക്, അല്ലെങ്കിൽ ഒരു നെറ്റ്‌വർക്ക് ഷെയർ തിരഞ്ഞെടുക്കുക.
   ഓരോ ഉപകരണവും അതിൽ സ്വന്തം `mythos-<id>.mythos` ഫയൽ എഴുതുകയും മറ്റുള്ളവയുടെ ഫയലുകൾ ഓരോ 5 സെക്കൻഡിലും വായിക്കുകയും ചെയ്യുന്നു.
3. **`.mythos` ഫയൽ**: മുഴുവൻ വർക്ക്‌സ്‌പേസിന്റെയും മാനുവൽ എക്‌സ്‌പോർട്ട്/ഇമ്പോർട്ട് (ഇമെയിൽ, USB സ്റ്റിക്ക്…). ഇമ്പോർട്ട് ലയിപ്പിക്കുന്നു, ഒന്നും മായ്ച്ചെഴുതുന്നില്ല.

ഉപകരണങ്ങൾ മാറ്റങ്ങൾ കൈമാറുന്നു: A, B-യുമായും B, C-യുമായും ബന്ധിപ്പിച്ചിട്ടുണ്ടെങ്കിൽ, A-യുടെ മാറ്റങ്ങൾ C-യിൽ എത്തും.

## പിന്തുണയ്ക്കുന്ന ഫോർമാറ്റുകൾ

| | ഇമ്പോർട്ട് | എക്‌സ്‌പോർട്ട് |
|---|---|---|
| ടെക്‌സ്റ്റ് | .docx, .html, .txt, .md | .docx, PDF (പ്രിന്റ്) |
| സ്‌പ്രെഡ്‌ഷീറ്റ് | .xlsx, .xls, .ods, .csv | .xlsx, .csv |
| പ്രസന്റേഷനുകൾ | .pptx | .pptx, PDF (പ്രിന്റ്) |

രൂപകൽപ്പനയെ നയിച്ച Word, Excel, PowerPoint എന്നിവയുടെ പ്രവർത്തന വിശകലനത്തിന് [docs/ANALYSE.md](../../docs/ANALYSE.md) (ഫ്രഞ്ചിൽ) കാണുക.

## ഘടന

```
src/main.js            ഹോം, റൂട്ടിംഗ്, ഫയൽ ഇമ്പോർട്ട്
src/store.js           ലോക്കൽ സംഭരണം (Y.Doc + IndexedDB), ലൈബ്രറി
src/sync/              സിങ്ക് പ്രോട്ടോക്കോൾ, WebRTC, പങ്കിട്ട ഫോൾഡർ, ഇന്റർഫേസ്
src/apps/writer.js     വേഡ് പ്രോസസ്സർ (ProseMirror/Tiptap)
src/apps/sheet.js      സ്‌പ്രെഡ്‌ഷീറ്റ് (canvas ഗ്രിഡ്)
src/apps/formula.js    ഫോർമുല എഞ്ചിൻ
src/apps/slides.js     പ്രസന്റേഷനുകൾ
src/io/                docx / xlsx / pptx പരിവർത്തനങ്ങൾ
electron/              ഡെസ്‌ക്‌ടോപ്പ് ആപ്പ് (Windows, Linux)
android/               Android പ്രോജക്റ്റ് (Capacitor)
```

## അറിയപ്പെടുന്ന പരിമിതികൾ

- ടെക്‌സ്റ്റ്: മാറ്റങ്ങളുടെ ട്രാക്കിംഗ്, കമന്റുകൾ, ഹെഡർ/ഫൂട്ടർ, സ്ക്രീനിലെ യഥാർത്ഥ പേജ് വിഭജനം എന്നിവ ഇല്ല
  (പ്രിന്റ് ചെയ്യുമ്പോഴും .docx-ലും പേജ് ബ്രേക്കുകൾ പാലിക്കപ്പെടുന്നു).
- സ്‌പ്രെഡ്‌ഷീറ്റ്: ചാർട്ടുകൾ, സെൽ ലയനം, കണ്ടീഷണൽ ഫോർമാറ്റിംഗ്, പിവറ്റ് ടേബിളുകൾ എന്നിവ ഇല്ല;
  .xlsx ഇമ്പോർട്ട് മൂല്യങ്ങൾ, ഫോർമുലകൾ, കോളം വീതി, ബോൾഡ് എന്നിവ തിരികെ കൊണ്ടുവരുന്നു, എല്ലാ സ്റ്റൈലുകളും അല്ല.
- പ്രസന്റേഷനുകൾ: ഓരോ ടെക്‌സ്റ്റ് ബോക്‌സിനും ഒരു സ്റ്റൈൽ (വാക്ക് തോറുമുള്ള ഫോർമാറ്റിംഗ് ഇല്ല), ആനിമേഷനുകൾ ഇല്ല;
  .pptx ഇമ്പോർട്ട് ടെക്‌സ്റ്റുകൾ, ആകൃതികൾ, ചിത്രങ്ങൾ, നിറങ്ങൾ, കുറിപ്പുകൾ എന്നിവ എടുക്കുന്നു, പക്ഷേ മാസ്റ്ററുകളും തീമുകളും അല്ല.
- ഓരോ തവണ തുറക്കുമ്പോഴും നേരിട്ടുള്ള ജോടിയാക്കൽ വീണ്ടും ചെയ്യണം (ഉപകരണങ്ങൾ കണ്ടെത്താൻ സെർവർ ഇല്ല).
