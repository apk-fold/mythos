**Συγχρονισμός με τετραψήφιο κωδικό**: σε μια συσκευή, *Συγχρονισμός → Εμφάνιση κωδικού*· στην άλλη, *Εισαγωγή κωδικού*. Ο κωδικός χρησιμεύει μόνο για να βρεθούν οι συσκευές σε έναν αναμεταδότη (ntfy.sh, αλλάζει στις Ρυθμίσεις), και η πρόσκληση είναι εκεί κρυπτογραφημένη. Έπειτα τα έγγραφά σας περνούν απευθείας από τη μία συσκευή στην άλλη.

Επεξεργαστής κειμένου, υπολογιστικό φύλλο και παρουσιάσεις σε μία εφαρμογή, για **Windows, Linux και Android**.
Τα αρχεία μένουν στις συσκευές σας· ο συγχρονισμός γίνεται απευθείας από συσκευή σε συσκευή.

## Εγκατάσταση

| Σύστημα | Αρχείο | Τοποθεσία |
|---|---|---|
| Windows | `Mythos-Setup-1.1.0.exe` (πρόγραμμα εγκατάστασης) ή `Mythos-Portable-1.1.0.exe` | `release/` |
| Linux | `Mythos-1.1.0-x64.tar.gz` (αποσυμπίεση και εκκίνηση του `./mythos`)· το AppImage μεταγλωττίζεται σε Linux με `npm run dist:linux` | `release/` |
| Android | `app-debug.apk` | `android/app/build/outputs/apk/debug/` |

Τα αρχεία δεν είναι υπογεγραμμένα: το Windows SmartScreen θα ζητήσει «Περισσότερες πληροφορίες → Εκτέλεση ούτως ή άλλως»,
και το Android θα ζητήσει να επιτρέψετε την εγκατάσταση εφαρμογών από άγνωστες πηγές.

## Νέα μεταγλώττιση

```sh
npm install
npm run dev          # έκδοση browser για ανάπτυξη (http://localhost:5173)
npm start            # εφαρμογή επιφάνειας εργασίας
npm run dist:win     # πρόγραμμα εγκατάστασης Windows → release/
npm run dist:linux   # AppImage + tar.gz → release/ (κατά προτίμηση σε Linux)
npm run android      # αντιγράφει τον ιστότοπο στο android/, και μετά:
cd android && gradlew assembleDebug   # JAVA_HOME = JDK 21
```

## Συγχρονισμός χωρίς διακομιστή

Κάθε έγγραφο είναι ένα **Yjs CRDT** αποθηκευμένο στο IndexedDB. Δύο συσκευές που τροποποίησαν το ίδιο έγγραφο εκτός σύνδεσης
συγχωνεύουν αυτόματα τις αλλαγές τους, χωρίς συγκρούσεις και χωρίς το «κερδίζει η τελευταία έκδοση».

Τρεις τρόποι να συνδέσετε τις συσκευές (πίνακας **Συγχρονισμός**):

1. **Άμεση σύζευξη (WebRTC)**: η συσκευή A εμφανίζει έναν κωδικό QR πρόσκλησης, η B τον σαρώνει (ή επικολλά τον κωδικό)
   και εμφανίζει έναν κωδικό QR απάντησης που σαρώνει με τη σειρά της η A. Στη συνέχεια η σύνδεση είναι κρυπτογραφημένη από άκρο σε άκρο (DTLS),
   σε πραγματικό χρόνο. Σε τοπικό Wi-Fi δεν χρησιμοποιείται κανένας διακομιστής· η επιλογή «μέσω Internet» χρησιμοποιεί έναν δημόσιο διακομιστή STUN
   μόνο για να βρει τη δημόσια διεύθυνση (κανένα δεδομένο δεν περνά από αυτόν). Πρέπει να επαναλαμβάνεται κάθε φορά που ανοίγει η εφαρμογή.
2. **Κοινόχρηστος φάκελος** (Windows / Linux): επιλέξτε έναν φάκελο που συγχρονίζεται με Syncthing, ένα USB stick ή έναν κοινόχρηστο φάκελο δικτύου.
   Κάθε συσκευή γράφει εκεί το δικό της αρχείο `mythos-<id>.mythos` και διαβάζει των άλλων κάθε 5 δευτερόλεπτα.
3. **Αρχείο `.mythos`**: χειροκίνητη εξαγωγή/εισαγωγή όλου του χώρου εργασίας (email, USB stick…). Η εισαγωγή συγχωνεύει, δεν αντικαθιστά τίποτα.

Οι συσκευές μεταβιβάζουν τις αλλαγές: αν η A συνδέεται με τη B και η B με τη C, οι αλλαγές της A φτάνουν στη C.

## Υποστηριζόμενες μορφές

| | Εισαγωγή | Εξαγωγή |
|---|---|---|
| Κείμενο | .docx, .html, .txt, .md | .docx, PDF (εκτύπωση) |
| Υπολογιστικό φύλλο | .xlsx, .xls, .ods, .csv | .xlsx, .csv |
| Παρουσιάσεις | .pptx | .pptx, PDF (εκτύπωση) |

Δείτε το [docs/ANALYSE.md](../../docs/ANALYSE.md) (στα γαλλικά) για την ανάλυση της λειτουργίας του Word, του Excel και του PowerPoint που καθοδήγησε τον σχεδιασμό.

## Δομή

```
src/main.js            αρχική, δρομολόγηση, εισαγωγή αρχείων
src/store.js           τοπική αποθήκευση (Y.Doc + IndexedDB), βιβλιοθήκη
src/sync/              πρωτόκολλο συγχρονισμού, WebRTC, κοινόχρηστος φάκελος, διεπαφή
src/apps/writer.js     επεξεργαστής κειμένου (ProseMirror/Tiptap)
src/apps/sheet.js      υπολογιστικό φύλλο (πλέγμα canvas)
src/apps/formula.js    μηχανή τύπων
src/apps/slides.js     παρουσιάσεις
src/io/                μετατροπές docx / xlsx / pptx
electron/              εφαρμογή επιφάνειας εργασίας (Windows, Linux)
android/               έργο Android (Capacitor)
```

## Γνωστοί περιορισμοί

- Κείμενο: χωρίς παρακολούθηση αλλαγών, σχόλια, κεφαλίδες/υποσέλιδα ή πραγματική σελιδοποίηση στην οθόνη
  (οι αλλαγές σελίδας τηρούνται στην εκτύπωση και στο .docx).
- Υπολογιστικό φύλλο: χωρίς γραφήματα, συγχώνευση κελιών, μορφοποίηση υπό όρους ή συγκεντρωτικούς πίνακες·
  η εισαγωγή .xlsx ανακτά τιμές, τύπους, πλάτη στηλών και έντονα, όχι όλα τα στυλ.
- Παρουσιάσεις: ένα στυλ ανά πλαίσιο κειμένου (χωρίς μορφοποίηση λέξη προς λέξη), χωρίς κινούμενα εφέ·
  η εισαγωγή .pptx κρατά κείμενα, σχήματα, εικόνες, χρώματα και σημειώσεις, αλλά όχι τα υποδείγματα ή τα θέματα.
- Η άμεση σύζευξη πρέπει να γίνεται ξανά σε κάθε εκκίνηση (δεν υπάρχει διακομιστής για να βρει τις συσκευές).
