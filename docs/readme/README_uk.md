**Синхронізація за 4-значним кодом**: на одному пристрої виберіть *Синхронізація → Показати код*, на іншому — *Ввести код*. Код потрібен лише для того, щоб пристрої знайшли один одного на ретрансляторі (ntfy.sh, змінюється в Параметрах), і запрошення там зашифроване. Далі ваші документи передаються безпосередньо з одного пристрою на інший.

Текстовий редактор, таблиці й презентації в одному застосунку для **Windows, Linux і Android**.
Файли залишаються на ваших пристроях; синхронізація відбувається безпосередньо між пристроями.

## Установлення

| Система | Файл | Розташування |
|---|---|---|
| Windows | `Mythos-Setup-1.1.0.exe` (інсталятор) або `Mythos-Portable-1.1.0.exe` | `release/` |
| Linux | `Mythos-1.1.0-x64.tar.gz` (розпакувати й запустити `./mythos`); AppImage збирається під Linux командою `npm run dist:linux` | `release/` |
| Android | `app-debug.apk` | `android/app/build/outputs/apk/debug/` |

Файли не підписані: Windows SmartScreen попросить вибрати «Докладніше → Усе одно запустити»,
а Android попросить дозволити встановлення застосунків із невідомих джерел.

## Перезбирання

```sh
npm install
npm run dev          # браузерна версія для розробки (http://localhost:5173)
npm start            # настільний застосунок
npm run dist:win     # інсталятор для Windows → release/
npm run dist:linux   # AppImage + tar.gz → release/ (краще запускати під Linux)
npm run android      # копіює сайт у android/, потім:
cd android && gradlew assembleDebug   # JAVA_HOME = JDK 21
```

## Синхронізація без сервера

Кожен документ — це **Yjs CRDT**, що зберігається в IndexedDB. Два пристрої, які змінили той самий документ офлайн,
автоматично об'єднують свої зміни — без конфліктів і без правила «перемагає остання версія».

Три способи з'єднати пристрої (панель **Синхронізація**):

1. **Пряме спарювання (WebRTC)**: пристрій A показує QR-код запрошення, B сканує його (або вставляє код)
   і показує QR-код відповіді, який сканує A. Після цього з'єднання захищене наскрізним шифруванням (DTLS)
   і працює в реальному часі. У локальній мережі Wi-Fi сервер не використовується; варіант «через інтернет» звертається до публічного STUN-сервера
   лише щоб дізнатися публічну адресу (дані через нього не проходять). Потрібно повторювати під час кожного запуску застосунку.
2. **Спільна тека** (Windows / Linux): виберіть теку, що синхронізується через Syncthing, USB-накопичувач або мережеву теку.
   Кожен пристрій записує туди свій файл `mythos-<id>.mythos` і щоп'ять секунд читає файли інших.
3. **Файл `.mythos`**: ручний експорт/імпорт усього простору (пошта, USB-накопичувач…). Імпорт об'єднує дані й нічого не перезаписує.

Пристрої передають зміни далі: якщо A з'єднаний із B, а B — із C, зміни A дійдуть до C.

## Підтримувані формати

| | Імпорт | Експорт |
|---|---|---|
| Текст | .docx, .html, .txt, .md | .docx, PDF (друк) |
| Таблиці | .xlsx, .xls, .ods, .csv | .xlsx, .csv |
| Презентації | .pptx | .pptx, PDF (друк) |

Аналіз роботи Word, Excel і PowerPoint, на який спиралася розробка, — у [docs/ANALYSE.md](../../docs/ANALYSE.md) (французькою).

## Структура

```
src/main.js            головний екран, маршрутизація, імпорт файлів
src/store.js           локальне сховище (Y.Doc + IndexedDB), бібліотека
src/sync/              протокол синхронізації, WebRTC, спільна тека, інтерфейс
src/apps/writer.js     текстовий редактор (ProseMirror/Tiptap)
src/apps/sheet.js      таблиці (сітка на canvas)
src/apps/formula.js    рушій формул
src/apps/slides.js     презентації
src/io/                перетворення docx / xlsx / pptx
electron/              настільний застосунок (Windows, Linux)
android/               Android-проєкт (Capacitor)
```

## Відомі обмеження

- Текст: немає відстеження змін, коментарів, колонтитулів і справжнього розбиття на сторінки на екрані
  (розриви сторінок враховуються під час друку та в .docx).
- Таблиці: немає діаграм, об'єднання клітинок, умовного форматування та зведених таблиць;
  імпорт .xlsx переносить значення, формули, ширину стовпців і жирний шрифт, але не всі стилі.
- Презентації: один стиль на текстове поле (не можна форматувати окремі слова), немає анімацій;
  імпорт .pptx переносить тексти, фігури, зображення, кольори й нотатки, але не зразки слайдів і теми.
- Пряме спарювання потрібно повторювати під час кожного запуску (немає сервера, який знайшов би пристрої).
