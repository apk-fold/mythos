**Синхронизация по 4-значному коду**: на одном устройстве выберите *Синхронизация → Показать код*, на другом — *Ввести код*. Код нужен только для того, чтобы устройства нашли друг друга на ретрансляторе (ntfy.sh, меняется в Параметрах), и приглашение там зашифровано. Дальше документы передаются напрямую с одного устройства на другое.

Текстовый редактор, таблицы и презентации в одном приложении для **Windows, Linux и Android**.
Файлы остаются на ваших устройствах; синхронизация идёт напрямую между устройствами.

## Установка

| Система | Файл | Расположение |
|---|---|---|
| Windows | `Mythos-Setup-1.1.0.exe` (установщик) или `Mythos-Portable-1.1.0.exe` | `release/` |
| Linux | `Mythos-1.1.0-x64.tar.gz` (распаковать и запустить `./mythos`); AppImage собирается под Linux командой `npm run dist:linux` | `release/` |
| Android | `app-debug.apk` | `android/app/build/outputs/apk/debug/` |

Файлы не подписаны: Windows SmartScreen попросит выбрать «Подробнее → Выполнить в любом случае»,
а Android попросит разрешить установку приложений из неизвестных источников.

## Пересборка

```sh
npm install
npm run dev          # версия для браузера для разработки (http://localhost:5173)
npm start            # настольное приложение
npm run dist:win     # установщик для Windows → release/
npm run dist:linux   # AppImage + tar.gz → release/ (лучше запускать под Linux)
npm run android      # копирует сайт в android/, затем:
cd android && gradlew assembleDebug   # JAVA_HOME = JDK 21
```

## Синхронизация без сервера

Каждый документ — это **Yjs CRDT**, хранящийся в IndexedDB. Два устройства, изменившие один и тот же документ офлайн,
автоматически объединяют свои изменения — без конфликтов и без правила «побеждает последняя версия».

Три способа связать устройства (панель **Синхронизация**):

1. **Прямое сопряжение (WebRTC)**: устройство A показывает QR-код приглашения, B сканирует его (или вставляет код)
   и показывает ответный QR-код, который сканирует A. После этого соединение шифруется сквозным шифрованием (DTLS)
   и работает в реальном времени. В локальной сети Wi-Fi сервер не используется; вариант «через интернет» обращается к публичному STUN-серверу
   только чтобы узнать публичный адрес (данные через него не проходят). Сопряжение нужно повторять при каждом запуске приложения.
2. **Общая папка** (Windows / Linux): выберите папку, синхронизируемую через Syncthing, USB-накопитель или сетевую папку.
   Каждое устройство записывает туда свой файл `mythos-<id>.mythos` и каждые 5 с читает файлы остальных.
3. **Файл `.mythos`**: ручной экспорт/импорт всего пространства (почта, USB-накопитель…). Импорт объединяет данные и ничего не перезаписывает.

Устройства передают изменения дальше: если A связано с B, а B — с C, изменения A дойдут до C.

## Поддерживаемые форматы

| | Импорт | Экспорт |
|---|---|---|
| Текст | .docx, .html, .txt, .md | .docx, PDF (печать) |
| Таблицы | .xlsx, .xls, .ods, .csv | .xlsx, .csv |
| Презентации | .pptx | .pptx, PDF (печать) |

Анализ работы Word, Excel и PowerPoint, на который опиралась разработка, — в [docs/ANALYSE.md](../../docs/ANALYSE.md) (на французском).

## Структура

```
src/main.js            главный экран, маршрутизация, импорт файлов
src/store.js           локальное хранилище (Y.Doc + IndexedDB), библиотека
src/sync/              протокол синхронизации, WebRTC, общая папка, интерфейс
src/apps/writer.js     текстовый редактор (ProseMirror/Tiptap)
src/apps/sheet.js      таблицы (сетка на canvas)
src/apps/formula.js    движок формул
src/apps/slides.js     презентации
src/io/                конвертация docx / xlsx / pptx
electron/              настольное приложение (Windows, Linux)
android/               Android-проект (Capacitor)
```

## Известные ограничения

- Текст: нет режима правок, комментариев, колонтитулов и настоящей постраничной разметки на экране
  (разрывы страниц учитываются при печати и в .docx).
- Таблицы: нет диаграмм, объединения ячеек, условного форматирования и сводных таблиц;
  импорт .xlsx переносит значения, формулы, ширину столбцов и жирный шрифт, но не все стили.
- Презентации: один стиль на текстовый блок (нельзя форматировать отдельные слова), нет анимаций;
  импорт .pptx переносит тексты, фигуры, изображения, цвета и заметки, но не образцы слайдов и темы.
- Прямое сопряжение нужно повторять при каждом запуске (нет сервера, который нашёл бы устройства).
